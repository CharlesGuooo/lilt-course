LiLT 架构课

这门课把 LiLT 从输入到输出拆开讲一遍。LiLT 的文本流就是一个原封不动的 RoBERTa，它真正新增的只有两样：一条 192 维的 layout 流，以及每层一次的注意力分数相加。每一章对应 code/ 里的一个脚本，页面上的数字都来自用真实权重跑出的结果。

一张图看懂 LiLT

三句话讲清 LiLT
  1. 文本流就是 RoBERTa-base，参数名一一对应，一个都不多。坐标完全不进文本 embedding。
  2. layout 流是 LiLT 新增的部分，只有 6.1 M 参数。它把框变成 192 维向量，再过 12 层窄版 Transformer。它只看坐标、不看文字，所以和语言无关。
  3. BiACM：每一层把两条流的注意力分数相加，两条流共用这张注意力图，各自聚合自己的 value。预训练时用 DETACH 挡住 layout → 文本的梯度，所以 layout 流能接到别的语言的 RoBERTa 上。

怎么读这门课

  • 顺序：从第 0 章读到第 7 章。熟悉 RoBERTa 的话，第 1 章可以只看第 4、6 节。
  • 每章的结构：先提出这一章要回答的问题，再给图和公式，然后是脚本里的关键代码和真实输出，最后是要点。每节的编号和脚本打印的标题编号一致，比如第 4 章第 3 节对应 ch04_biacm.py 输出里的 “3. …”。
  • 颜色：全课统一，蓝 = 文本流，橙 = layout 流。
  • 标着 “试一试” 的框可以点、可以拖。数据图悬停能看具体数值，图下面都有数据表。

记号

记号含义LiLT-base 的值
L序列长度（token 数，含 <s> 和 </s>）最大 512；示例发票 66
dT文本流宽度768
dLlayout 流宽度 = dT / channel_shrink_ratio192
H注意力头数（两条流相同）12
dh每个头的维度：文本 / layout64 / 16
Nl层数（两条流相同）12
