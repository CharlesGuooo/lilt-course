第 03 章

Layout embedding

一个框 (x0, y0, x1, y1) 怎么变成一个 192 维向量：查 6 次表、拼成 768 维、线性投影到 192 维，再加上 layout 流自己的 1D 位置向量。这是 layout 流的入口，也是 LiLT 和 LayoutLM 第一个分岔的地方。

对应脚本 code/ch03_layout_embedding.py 运行 python ch03_layout_embedding.py

§1四张坐标表，六次查表

P2D = Linear( CAT( Ex0, Ey0, Ex1, Ey1, Eh, Ew ) )论文式 (2)

每张表的宽度是 hidden_size // 6 = 128，6 段拼起来正好是 768，再用一个线性层压到 192。宽和高不是直接给的，是现算的：h = y1 − y0，w = x1 − x0。

输入一个框，看它查了哪 6 行

选示例发票里的一个 segment，或者直接改坐标（归一化后的 0..1000）。试试列表最后两个“坏框”。

拼接顺序

论文式 (2) 写的顺序是 (xmin, xmax, ymin, ymax, width, height)，代码里实际拼的是 (x0, y0, x1, y1, h, w)。后面接的是一个学出来的线性层，顺序本身只是约定，但必须和权重训练时一致，所以以代码为准。

§3为什么还要再加 1D 位置

第 2 章说过，同一个 segment 里的词共用一个框。拿 “Invoice No:” 里的两个词来看：

python ch03_layout_embedding.py · §3真实权重
  token 11 'ĠInv' 框 [70, 127, 200, 145]
  token 13 'ĠNo' 框 [70, 127, 200, 145]
  两者的 P2D 完全一样？ True

Transformer 本身对顺序不敏感。如果 layout 流只有 P2D，这两个 token 在 layout 流里就无法区分。论文 2.1.2 节正是出于这个原因（“Transformer layers are permutation-invariant”）把 1D 位置又加了一次。

§4学到的坐标表是不是“平滑”的

坐标表是普通的 nn.Embedding，第 300 行和第 301 行之间没有任何显式约束。坐标的“连续性”只能从预训练数据里学出来。用真实权重看一下第 300 行和其他每一行的余弦相似度：

每隔 5 取一个 k；悬停看数值

python ch03_layout_embedding.py · §4真实权重
  cos(x=300, x=300 ) = +1.000
  cos(x=300, x=305 ) = +0.675
  cos(x=300, x=320 ) = +0.603
  cos(x=300, x=350 ) = +0.556
  cos(x=300, x=400 ) = +0.491
  cos(x=300, x=600 ) = -0.319
  cos(x=300, x=900 ) = +0.041

能读出三件事：

  1. 局部是平滑的，但窗口不对称：x 表在大约 260～400 之间相似度都在 0.46 以上，往左过了 250 就迅速掉到 0 附近（k = 220 时约为 0）。y 表的窗口更窄，大约只有 270～320。模型确实学到了“相邻坐标差不多”，只是这个“相邻”的范围各处不一样。
  2. 相邻也不等于相同：300 和 305 的相似度只有 0.675，这张表不是正弦位置编码那样的光滑函数。
  3. 远处不是单调衰减：x 表在 705 附近降到最低的 −0.54，在 745 到 750 之间突然从 −0.47 跳到 −0.15，之后一直在 0 附近；y 表的最低点在 910（−0.52）。这种突跳说明表里不同区段几乎是各学各的。坐标之间的远距离关系，主要还是靠后面 12 层注意力去处理。这里只看了一个参照点 300，换个参照点形状会不同，可以自己改脚本试。

和 LayoutLM 的对比

LayoutLM 把 2D 位置向量直接加到 768 维的文本 embedding 上，文本和坐标从第一层起就混在一起，只能一起预训练。LiLT 让坐标单独走一条 192 维的流，一点都不碰文本 embedding。代价是多了一条流，好处是文本流可以整个换掉（第 5 章）。

要点

  1. layout embedding = LN( Linear( 6 次查表拼成的 768 维 ) + 1D 位置 )，输出 192 维。
  2. 4 张坐标表各 1024 行；x0/x1 共用 x 表，y0/y1 共用 y 表，宽高现算；任何索引超出 0..1023 都会报错。
  3. 同框的词 P2D 完全相同，所以 layout 流也必须加 1D 位置。
  4. 学到的坐标表局部平滑、远处不单调；连续性来自数据，不是结构保证的。
